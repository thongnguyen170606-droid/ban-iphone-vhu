# 📱 VHU Apple Store - Website Bán Điện Thoại iPhone

## 🚀 Công nghệ sử dụng
- Backend: Node.js, Express.js
- Database: MySQL
- Frontend: HTML, CSS, JavaScript

## 🛠️ Hướng dẫn cài đặt cho Hội đồng
1. Import file `iphone_store_db.sql` vào MySQL (qua phpMyAdmin).
2. Mở Terminal tại thư mục code, gõ lệnh `npm install` để tải thư viện.
3. Gõ lệnh `node server.js` để khởi chạy server.
4. Truy cập web tại: `http://localhost:3000`
